# Boss 遭遇配置

Boss Encounter SO 保存开始血管、血管路径、非符／符卡分段、行为状态及整场动作。
实体 prefab 保留 Boss、BossHealth、BossController、BossHitbox 和外观配置。

## 整管模式配置

1. 创建 STG/Boss Encounter，指定 Boss prefab。
2. 添加血管，设置唯一 ID 和血量上限。非符可关闭“启用时限”；符卡可开启并设置正数秒数。打空换管始终启用。
3. 在每管内添加至少一个 Shooter 状态并指定 BehaviorFlow。
4. 对非末尾状态选择“本状态持续时间”或“本管剩余血量百分比”。状态顺序执行，不循环；末尾状态保持到血管结束。
5. 下拉选择开始血管和各管的 NextBar。NextBar 为空表示结束战斗；禁止循环。不可达血管不执行，也不计入 HUD。
6. 配置整场开场、击破、收尾动作以及状态入场、退场动作与指令。
7. 关卡使用 BossEncounterEntry 引用 SO；直接场景测试在 Boss 组件指定 Encounter。

“启用时限”默认开启；非符取消勾选即可。关闭时限不会影响管内按状态时间切换；只禁用整管超时换管，并隐藏 HUD 倒计时。

血管打空或启用时限后的超时优先于管内状态切换，当前状态收尾后进入下一管首状态。
切状态不回血；状态计时从正式进入开始，每次切状态重置。血管计时跨状态累计，
等待开场、入场和退场动作时暂停。切换期间自动保护血量，击破溢出伤害丢弃。
最终血管耗尽或超时都走整场结束和击破动作；当前状态执行一次退出指令，不执行退场动作。
超时原因可通过 Controller.LastBarTimedOut 读取，目前沿用既有结束奖励规则。

进入顺序为 EnterActions → EnterCommands → 行为；正常退出为停止行为 → ExitCommands → ExitActions。
等待动作取消或失败将停止并清理遭遇。手动清场不冒充击败。
编辑通过 SerializedProperty 支持 Undo 和 dirty；运行期间配置只读。重排状态会带上完整行为和演出。

旧顶层 Phases/Loop 数据保留供对照，不再参与 Encounter 执行，需要将阶段重新配置到所属血管。
旧的 ExitConditions/保护开关不参与管内状态切换。不会自动猜测旧阶段所属血管或改写资产。
每场遭遇克隆配置，隔离嵌套状态与动作；Boss 使用创建/销毁生命周期，不支持复用已执行实例。

EditMode 回归入口：BossEncounterTests（路径、状态时间、血量阈值、超时、过渡保护、克隆与 Undo）、
BossHudTests，以及保留给底层兼容 API 的 PhaseExitConditionTests 和 BossTransitionTests。

倒计时布局和已有 HUD 的补建见 [HUD 操作说明](../../UI/README.md#boss-时限倒计时)。

## 非符与符卡共用一管血

1. 按上面的流程建立血管，在 Inspector 点击“将本管转为单个分段（保留原配置，可撤销）”。
2. 将第一段命名为非符，设置类型、血量、承伤倍率、颜色及是否限时。
3. 点击“添加符卡分段”，配置符卡血量、颜色、倍率和独立时限。使用上下箭头调整执行顺序，稳定 ID 不随排序改变。
4. 在每段内至少配置一个 Shooter 状态并指定 BehaviorFlow；一段可包含多个弹幕状态。
5. 符卡宣言放在符卡段首状态的 EnterActions，需要等待时开启动作序列的 WaitForCompletion。
6. 确认 Inspector 无配置错误后，沿用原 Encounter 的关卡或场景接入方式。

例如非符血量 4000、白色、承伤倍率 1、不限时；符卡血量 6000、红色、倍率 0.5、限时 60 秒。
整管合计 10000，白色占右侧 40% 并先消耗，红色占左侧 60%；原始伤害 100 在符卡段扣血 50。
段内需要三种弹幕时，可令前两个状态分别在本段剩余 70% 和 30% 时切换，最后状态保持到本段结束。

`HealthBar.Segments` 非空时，血管上限由分段血量合计，原整管血量、时限和状态配置不参与分段数据校验。
分段 ID 在本管内唯一；状态血量阈值以本段为基准，必须在 0 与 100 之间严格递减。
承伤倍率为有限非负数，0 表示不扣血，1 表示正常；颜色不影响承伤。

`BossHealth` 独立持有各段剩余血量，当前段打空即阻止后续伤害，溢出不进入下一段。
整管比例包含当前段剩余血量和未来段血量；分段耗尽事件与整管耗尽事件分别通知。
配置中的分段对象不保存剩余血量。

在 Encounter Inspector 展开血管，使用“将本管转为单个分段”保留血量、时限并复制状态；该操作支持 Undo。
随后可添加非符或符卡分段、调整顺序，并在每段内配置状态。新增非符默认白色、无时限，符卡默认红色、60 秒；
修改类型不会覆盖已配置的颜色与时限。列表显示整管合计血量和各段占比，删除最后一段恢复原整管配置。
旧配置保留且不自动迁移；转换后的状态与旧状态独立，撤销或恢复旧模式不会混入分段编辑结果。

Controller 按血管、分段、状态顺序推进。分段打空或超时后退出当前状态，复用状态退场与下一段首状态入场动作；
过渡期间无敌且暂停计时。段内换状态不重置分段计时；最后一段结束才换管，最后一管结束沿用死亡收尾。
超时清空本段但不发送击破通知。`LastSegmentEndReason` 与对应管、段索引记录最近结束的分段，区分击破、超时、取消；
现有退出指令奖励规则保持不变，尚未增加符卡收取判定。
奖励仍配置在状态 ExitCommands；被跳过或未进入的状态不补发奖励，不要假定本段末状态一定执行。

当前 HUD 倒计时读取当前分段，血条按分段颜色和血量比例显示，先执行的段从右侧消耗；切段不拉伸剩余血量。
EditMode 回归入口为 `BossHealthSegmentTests` 和 `BossSegmentControllerTests`。
多色显示与旧 HUD 补建见 [HUD 分段血条说明](../../UI/README.md#boss-多色分段血条)。
