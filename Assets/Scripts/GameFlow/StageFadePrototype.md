# 关间渐变配置与视觉预览

StageFadePrototype 提供手动视觉预览和正式换关的局部渐变；组件名称保留以兼容已有场景。
现有标题开局仍使用原来的滑动黑幕。手动预览不推进关卡，也不停止刷怪、射击、受伤或掉落。
正式关间流程在通关结算、清场及必要的复活完成后先显示单关计分；玩家松开并重新按 Z 确认后，才复用本组件的有效 BattleArea 配置，驱动渐黑、下一关启动和渐亮。计分与正式转场期间锁定玩家操作，战斗限制保持到下一关揭幕完成。未配置本组件时使用全屏渐变。末关确认后进入整局结果页，不执行下一关转场。手动播放仍只验证视觉，不推进关卡。

## 配置与手动预览

1. 打开 Gameplay 或测试场景，选中绘制玩家的正交战斗 Camera。
2. 执行 `STG > Game Flow > Create Fade Prototype For Selected Camera`。
   工具创建并选中 StageFadePrototype，支持一次 Undo；场景标记 dirty，由使用者保存。
3. 在原型组件点击“创建并绑定 BattleArea”。工具在唯一 HUD LayoutRoot 下创建空矩形，初始范围是左侧 70%，仅作占位。用 Rect Tool 调整到实际主画面边界，排除侧栏并保存场景。已有矩形也可以直接拖入 Battle Area。没有 HUD LayoutRoot 时，在 HUD Canvas 下手动创建空 UI 矩形并绑定。随后在安全的空场进入 Play，等待开局揭幕完成。
4. 在组件 Inspector 点击“播放渐黑 / 全黑移动 / 渐亮”，随后将焦点移回 Game 窗口。
5. 持续按方向键或 Shift，验证渐黑、全黑停留和渐亮全过程能够移动。
   可调整停留时间以留出切回 Game 窗口的时间。
6. 点击取消、禁用组件或退出 Play，确认黑幕消失。重复播放验证无残留。

## 表现边界

黑幕与机体裁剪共享显式 BattleArea，独立于相机 viewport。每帧将 HUD 矩形转换成屏幕边界，跟随锚点、CanvasScaler 和窗口尺寸。区域必须位于主屏幕的 Screen Space Canvas 下且屏幕轴对齐。侧栏必须位于 BattleArea 之外。手动预览在配置无效时拒绝播放；正式换关开始时若没有可用组件，则使用全屏渐变，全黑时机体也会被遮住。局部渐变开始后若配置失效，则进入可返回标题的错误状态，不在途中切换呈现方式。
组件读取真实玩家根节点的 Simple SpriteRenderer，使用其实时 sprite、颜色、翻转、投影位置和尺寸绘制 UI 机体。
不克隆玩家逻辑，不修改玩家 Layer、Renderer 或控制锁，不修改 Time.timeScale。
黑幕上只映射根节点机体，子机与判定点随普通画面变黑。

当前面向项目中的平面精灵机体和主屏幕正交相机。自定义 Sprite shader、倾斜透视、
多 Renderer 组合机体不在原型支持范围；透明边缘在渐变途中需检查重叠表现。
首次开局或返回标题时手动预览拒绝启动或自动取消；正式换关由 GameFlowController 独占驱动。全黑停留时间只用于手动预览，正式换关的全黑阶段由下一关准备和启动驱动。每个 Gameplay 场景建议只启用一份此组件。

## Unity 验收

- 渐变不是横向滑动；全黑时只显示可移动机体，位置和缩放与原机体一致。
- 低速、贴近四边、窗口缩放、翻转和精灵动画下无明显错位。
- 取消、组件禁用、场景卸载及重复播放无黑幕残留。
- 工具重复执行不创建第二份组件；Undo / Redo 和保存重开后相机绑定正确。
- 配置两关序列，确认清场后停留单关计分界面，松开并重新按 Z 后才开始渐变，下一关揭幕后才恢复玩家操作和时间轴；禁用组件后验证全屏渐变回退。
